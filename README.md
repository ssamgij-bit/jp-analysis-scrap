# 일본 주식 분석글 모음 봇 (jp-analysis-scrap)

일본 개별주 분석글(note·はてな·네이버)을 30분마다 모아 제목·요약을 한국어로 번역해 텔레그램 채널 '일본개별주'에 올립니다. 비용 0원(GitHub Actions + 무료 번역).

| 작업 | 주기 | 파일 |
|---|---|---|
| 새 글 수집·필터·번역·게시 | 30분마다 | bot.py |
| 소스 활동 점검·신규 소스 발굴·주간 리포트 | 매주 일요일 07:00 KST | maintain.py |

## 소스 직접 관리
sources.yaml에서 status를 바꾸면 됩니다: active / dormant / blocked(영구 제외, 자동 편입도 막음).

## 게시 기준 요약
- note 작성자(jpstock): 실제 상장 종목코드가 있고 본문 1,200자 이상인 글
- note 해시태그 발굴(discover): 3,000자 이상 + 종목코드 + 재무 용어 4개 이상, 유료·AI 작성·입문 글 제외 → 🔎발굴 표시
- 공통 제외: 일일 시황·운용보고·포트폴리오 공개·가상화폐, 제목에 미국 티커만 있는 글

## 주간 자동 업데이트
- 60일 넘게 새 글 없는 소스는 dormant, 다시 글 올리면 active
- note 신규 작성자: 유료 50% 미만, AI 작성 1편 이하, 개별주 글 50% 이상, 품질 점수 6 이상, 팔로워 많은 순 우선
- Substack 수집·발굴은 꺼져 있음(maintain.py의 ENABLE_SUBSTACK_DISCOVERY)
